# Commercial Configuration

- **Free foundation preserved:** imports, original report access, source/evidence inspection, basic charts — never paywalled. The Studio sells transformation/production, not access to one's own information.
- **Tiers (provisional hypotheses, configurable in `js/commerce.js` — NOT market-validated):** Free $0 · Explorer $9/mo · Creator $24/mo · Collector $49/mo · Studio Pro $99/mo.
- **Credits:** per-artifact estimates in `COSTS` (atlas 20, evidence pack 5, podcast script 15, deck 15, artwork 10, storyboard 10, report 20, workbook 8). Ledger: reserve at generation → reconcile on completion → refund on failure/cancel. Duplicate billing impossible in the local ledger (single reserve per job, refund is idempotent-guarded).
- **Margin:** not claimed. Provider costs are $0 in this local build because no paid provider is connected; any profitability statement would be hypothetical and is therefore not made (§12.5).
- **Enforcement honesty:** with no payment provider connected, premium artifacts generate as clearly labeled **previews**. There is no fake paywall and no fake charge. Connecting Stripe (server-side) is the unlock path — see REMAINING_BLOCKERS.
- **Upgrade UX:** cost review shows deliverable, credit price, revision policy, and provider status *before* confirmation. No transformation-pressure claims anywhere in copy.
